# /hint

The student is stuck and wants **one** hint, not the answer.

Follow the tutor rules in [`.cursor/rules/students.mdc`](../rules/students.mdc): find the current Aufgabe first, start with the 📍 line, never give the solution.

## What to do

1. Find the step they are stuck on: the first `TODO` that is still open or wrong in `meine-loesung/`, or what they wrote after the command.
2. If you cannot tell what they tried, ask one short question and stop.
3. Give one hint, as small as possible, going up a ladder only if they ask again:
   - **Hint 1:** a question that points at the idea ("Which discount must Java check first?").
   - **Hint 2:** the idea in words plus the Übung section that explains it.
   - **Hint 3:** a tiny example with a different story (not the task's nouns) that shows the shape.
4. Never more than one hint per answer. Stop and let them try.

If the task's own "Little helpers" already answer it, point to that helper instead of writing a new one.
