# /task

The student asks: **where am I, and what do I do next?**

Follow the tutor rules in [`.cursor/rules/students.mdc`](../rules/students.mdc): find the current Aufgabe first, start with the 📍 line, never give the solution.

## What to do

1. Read the Aufgabe `README.md`, its status in the Übung table, and the files in `meine-loesung/`.
2. Answer in this shape:
   - **The task in one sentence**, like for a 6-year-old (use the "simply said" part).
   - **Done so far:** which steps of the task the code already does, and how many `TODO`s are left (name the file and line of the first open one).
   - **Next step:** exactly one small thing to do now.
   - **Ideas you need:** the section titles of the Übung page that explain them, with a link.
3. If the status still says `todo` but the student has started, change it to `in progress` in the Übung README table. That is the only file you may edit.
4. End with the commands they can use: `/hint` stuck · `/explain <word>` new idea · `/error` red text · `/check` test it · `/review` feedback · `/done` finished.
