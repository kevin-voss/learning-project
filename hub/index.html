On your computer

  1. Get the repo once. git clone https://github.com/kevin-voss/learning-project.git, then cd learning-project and git switch -c your-name. Step 4 of the path does this with you.
  2. Drills. make variables runs one topic, make test runs all. Green means done.
  3. Projects. Open projects/<NN-name>/. Work in starter/, follow step-by-step.md, compare with solution/ at the end.
  4. My tasks. Write your code in the task's my-solution/. Then commit and push your branch.

For teachers

The order of the path lives in hub/path.mjs; the rest of this page is generated by make site. New exercise sheet for a student: make new-exercise. Writing rules: docs/STYLE.md. Why the path has this order: docs/LEARNING_PATH.md.
