Work locally

This website shows everything in the repository. To do the work, clone it and open your own folder.

1 · Clonegit clone <repo-url>, then cd learning-project. Every sheet here is a .md file in the same path.
2 · Find your taskOpen students/<your-name>/. Read README.md, then TASK.md.
3 · BuildWrite code only in starter/. Drills: make test. Projects: follow docs/step-by-step.md.
4 · CheckDone? Compare with solution/ and set the status in your subject README.md to done.
