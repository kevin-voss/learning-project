# What is a program?

> [!PICTURE]
> A program is a **recipe**. A recipe tells a cook what to do, one step after the other: take two eggs, crack them, stir. A program tells a computer what to do, one step after the other.

## The idea

A computer is a very fast, very obedient cook. It never guesses. It does exactly what the recipe says, in order.

The recipe has to be written in a language the computer understands. That language is **code**. On this path you learn two: **JavaScript** (for web pages) and **Java** (for big programs and servers).

Why learn it? Because then you can make things: a page about you, a game, a shopping list, a weather app, a parcel tracker. Every one of those is on this path.

## Tiny example

This is a whole program. It has one step:

```js
console.log('Hello!')
```

`console.log` means "write this on the screen". The computer writes `Hello!`.

## How this path works

Every step has one of three marks:

| Mark | You … |
|------|-------|
| **Read** | read a short page like this one |
| **Do** | build or practise something on your computer |
| **Check** | ask yourself: can I really do this? Tick it only if yes |

Your ticks are saved in this browser. The **Continue** button always opens your next step.
