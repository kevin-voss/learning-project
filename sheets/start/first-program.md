# Your first program

> [!PICTURE]
> Every web browser has a **little workshop** hidden inside. It is called the **console**. You type a line of code, press Enter, and the browser does it right away.

## The idea

You do not need to install anything yet. The browser you are using right now can run JavaScript.

## Tiny example

```js
console.log('Hello, I am Sam!')
2 + 3
'pizza'.toUpperCase()
```

Line 1 writes a sentence. Line 2 adds two numbers. Line 3 shouts a word.

> [!TRY]
> 1. Press **F12** (on a Mac: **Cmd + Option + J**). A panel opens. Click the tab called **Console**.
> 2. Type `console.log('Hello, I am Sam!')` with your own name and press **Enter**.
> 3. Type `2 + 3` and press Enter. Then try `10 * 7`.
> 4. Type `'pizza'.toUpperCase()` and press Enter.
>
> You should see: your sentence, then `5`, then `70`, then `'PIZZA'`.

If you see a red message, that is OK. Red means "I did not understand". Look for a missing `'` or `)` and try again.

> [!CHECK]
> 1. Where did your code run?
>    <details><summary>Answer</summary>In the browser console, inside the web browser.</details>
> 2. What does `console.log(...)` do?
>    <details><summary>Answer</summary>It writes what is inside the brackets on the screen.</details>
> 3. What does red text in the console mean?
>    <details><summary>Answer</summary>The computer did not understand a line. Fix it and try again.</details>

You just wrote and ran code. Every program on this path, even a big server, starts like this.

**Next:** go back to the path and open step 3, the terminal.
