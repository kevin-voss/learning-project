# Glossary: words in plain English

> [!PICTURE]
> A **picture dictionary**. One word, one short meaning. If a page uses a word you do not know, look here first.

The words are in A to Z order. The bigger lessons link to their own pages; this page only gives the short meaning.

## A

| Word | Meaning |
|------|---------|
| **API** | A menu of questions one program may ask another program, with the shape of each answer. |
| **Argument** | A value you hand to a function or a command, like `'Berlin'` in `showWeather('Berlin')`. |
| **Array** | A shelf with numbered boxes, counting from 0. |
| **async** | A word in front of a JavaScript function that lets it use `await` inside. |
| **Attribute** | Extra information inside an HTML tag, like `href` in `<a href="…">`. |
| **await** | "Wait here until the answer is ready", used with a Promise. |

## B

| Word | Meaning |
|------|---------|
| **Boolean** | A value that is only `true` or `false`. |
| **Branch** | Your own line of commits in Git, like a second photo album next to `main`. |
| **Browser** | The app that shows web pages: Chrome, Firefox, Safari, Edge. |
| **Bug** | A mistake in code that makes it do the wrong thing. |
| **Build** | Turning your source files into something that can run or be published. |
| **Bun** | A program that runs JavaScript outside the browser; the drills use it to run tests. |

## C

| Word | Meaning |
|------|---------|
| **Class** | A cookie cutter in Java: it describes the shape every object made from it has. |
| **CLI** | A command-line interface: a program you use by typing commands in the terminal. |
| **Client** | The program that asks, for example your browser asking a server for a page. |
| **Clone** | Copying a whole Git repository from GitHub onto your computer. |
| **Code** | The text of a program, written in a programming language. |
| **Command** | One instruction you type in the terminal, like `ls` or `git status`. |
| **Commit** | One saved snapshot of your files in Git, with a short message. |
| **Compile** | Translating Java code into bytecode the computer can run (`javac` does this). |
| **Component** | In React, a function that returns a piece of the page. |
| **Condition** | A question that is true or false, used by `if` to choose what happens. |
| **Conflict** | Git cannot merge on its own because two people changed the same lines. |
| **Console** | A place where you type code or commands and see the answer right away. |
| **Container** | A running program inside its own small box with everything it needs (Docker). |
| **CSS** | The language that paints a web page: colours, sizes, spacing, layout. |

## D

| Word | Meaning |
|------|---------|
| **Database** | A program that stores data in an organised way and finds it again fast. |
| **Dependency** | A package your project needs and downloads, like a library from npm or Maven. |
| **Diff** | The list of lines that were added or removed between two versions of a file. |
| **Docker** | A tool that packs a program and everything it needs into a box that runs the same everywhere. |
| **Docker Compose** | A file and a command that start several containers together, like a database and an app. |
| **Dockerfile** | The recipe Docker follows to build an image. |
| **DOM** | The tree of all elements on a web page, which JavaScript can read and change. |
| **DTO** | A data transfer object: the shape of the data a server receives or sends, often as JSON. |

## E

| Word | Meaning |
|------|---------|
| **Editor** | The app where you write code, for example VS Code. |
| **Element** | One piece of a web page, made by a tag, like a heading or a button. |
| **Environment variable** | A named setting outside your code, like `PORT=8080`, that a program reads when it starts. |
| **Event** | Something that happens on a page, like a click or a key press, that code can react to. |
| **Exception** | An error that stops the normal flow, unless you catch it with `try` / `catch`. |
| **Exit code** | The number a program returns when it ends: 0 means OK, anything else means an error. |

## F

| Word | Meaning |
|------|---------|
| **fetch** | The JavaScript function that sends an HTTP request and gives back a Promise. |
| **Field** | A value an object keeps, like `name` inside a `Dog` object. |
| **Flex** | A CSS layout that puts children in a row or a column. |
| **Folder** | A box for files on your computer; also called a directory. |
| **Function** | A small machine: values go in, a result comes out. In Java it is called a method. |

## G

| Word | Meaning |
|------|---------|
| **GET** | The HTTP method for reading data without changing anything. |
| **Git** | A program that saves snapshots of your project so you can look back and undo. |
| **GitHub** | A website that keeps Git repositories online so people can share them. |

## H

| Word | Meaning |
|------|---------|
| **Hook** | A React function like `useState` or `useEffect` that a component uses to keep data or react to changes. |
| **HTML** | The language that builds the skeleton of a web page with tags. |
| **HTTP** | The rules browsers and servers use to send requests and responses to each other. |
| **HTTPS** | HTTP with a lock: nobody in between can read or change the messages. |

## I

| Word | Meaning |
|------|---------|
| **Image** | A packed, read-only box with a program and all it needs; Docker starts containers from it. |
| **Index** | The number of a box on an array shelf; the first one is 0. |
| **IP address** | The number that finds one computer on a network, like a house address. |

## J

| Word | Meaning |
|------|---------|
| **Java** | The main language on this path, used for big programs and servers. |
| **JavaScript** | The language that runs in every web browser; your first language on this path. |
| **JDK** | The Java Development Kit: what you install to write and run Java. |
| **JSON** | Data written as plain text, like a packing list taped on a parcel. |
| **JSX** | HTML-like writing inside JavaScript, used by React. |
| **JUnit** | The tool Java uses to run tests. |
| **JVM** | The Java Virtual Machine: the program that runs compiled Java code. |

## K

| Word | Meaning |
|------|---------|
| **Key** | The label you use to find a value, like `city` in `{ city: 'Berlin' }`. |

## L

| Word | Meaning |
|------|---------|
| **List** | A row of values in order that can grow, like `ArrayList` in Java. |
| **localStorage** | A small drawer in the browser that keeps strings after you reload the page. |
| **Loop** | Code that repeats, with `for` or `while`. |

## M

| Word | Meaning |
|------|---------|
| **main** | In Java, the method where the program starts. In Git, the main branch everyone shares. |
| **Map** | A collection of key → value pairs, like a phone book (`HashMap` in Java). |
| **Maven** | The Java build tool: it downloads libraries, compiles, and runs the tests. |
| **Media query** | A CSS rule that only works on some screens, for example on a phone. |
| **Merge** | Joining the commits of one Git branch into another. |
| **Method** | A function that belongs to a class or an object, like `dog.bark()`. |

## N

| Word | Meaning |
|------|---------|
| **Node.js** | A program that runs JavaScript on your computer instead of in the browser. |
| **npm** | The package manager for JavaScript: it downloads libraries listed in `package.json`. |
| **null** | "No value here." Using it like a real value causes an error. |

## O

| Word | Meaning |
|------|---------|
| **Object** | One thing with its own data: one cookie made with a class (Java) or `{ key: value }` (JavaScript). |
| **Open-Meteo** | A free weather service on the internet that needs no key; the weather projects use it. |

## P

| Word | Meaning |
|------|---------|
| **Package** | In Java, a folder of classes that belong together. In JavaScript, a library you install with npm. |
| **package.json** | The file that names a JavaScript project, its scripts and its packages. |
| **Parameter** | The name a function gives to a value it receives, like `city` in `function show(city)`. |
| **Port** | A numbered door on a computer; each server program listens at one, like 8080. |
| **POST** | The HTTP method for sending new data to a server. |
| **Program** | A recipe for a computer: steps it follows in order. |
| **Promise** | A note that says "your result comes later". |
| **Props** | The values a parent React component hands to a child component. |
| **Pull** | Getting the newest commits from GitHub into your copy (`git pull`). |
| **Pull request** | A request on GitHub: "please look at my branch and merge it". |
| **Push** | Sending your commits up to GitHub (`git push`). |

## Q

| Word | Meaning |
|------|---------|
| **Query** | A question you ask a database, written in SQL. |

## R

| Word | Meaning |
|------|---------|
| **Registry** | A shop on the internet for packages or images, like npm or Docker Hub. |
| **Repository** | In Git, a project folder with its whole history. In a server, the class that loads and saves data. |
| **Request** | The message a client sends to a server: "please give me …" or "please save …". |
| **Response** | The answer a server sends back, with a status code and usually some data. |
| **REST** | A common way to design a web API with URLs and HTTP methods like GET and POST. |

## S

| Word | Meaning |
|------|---------|
| **Selector** | The part of a CSS rule or `querySelector` call that says which elements you mean, like `h1` or `.card`. |
| **Server** | A program that waits for requests and sends responses. |
| **Service** | In a server, the class that holds the rules ("a title may not be empty"). |
| **Shell** | The program inside the terminal that reads your commands and runs them. |
| **SQL** | The language for asking a database questions and changing its data. |
| **Staging area** | The waiting room in Git: files you chose with `git add` for the next commit. |
| **State** | Data that can change while a program runs, like the items in a React todo list. |
| **Static site** | Web pages served as plain files, with no program on the server building them. |
| **Status code** | The number in an HTTP response: 200 means OK, 404 means not found, 500 means the server broke. |
| **String** | A piece of text in quotes, like `'pizza'`. |

## T

| Word | Meaning |
|------|---------|
| **Table** | Data in a database stored in rows and columns, like a spreadsheet. |
| **Tag** | In HTML, a marker like `<p>` that says what a piece of text is. In Docker, the version label of an image. |
| **Template literal** | Text in backticks that can hold values: `` `Hi ${name}` ``. |
| **Terminal** | A window where you type commands to your computer instead of clicking. |
| **Test** | A small piece of code that checks other code gives the right answer. |
| **Type** | The kind of a value: number, text, true/false, list. Java checks types before running. |

## U

| Word | Meaning |
|------|---------|
| **URL** | A web address, like `https://open-meteo.com/en/docs`. |

## V

| Word | Meaning |
|------|---------|
| **Value** | One piece of data: a number, a text, `true`, a list. |
| **Variable** | A labelled box that holds a value. |
| **Vite** | A tool that runs and builds modern web projects, used for the React extra. |
| **Volume** | A folder that keeps a container's data safe when the container stops. |

## W

| Word | Meaning |
|------|---------|
| **Working tree** | Your files as they are on disk right now, before you commit. |
| **WSL** | Windows Subsystem for Linux: Ubuntu running inside Windows. |
