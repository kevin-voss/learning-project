# Glossary: words in plain English

One word, one short meaning. If a page uses a word you do not know, look here first.

| Word | Meaning |
|------|---------|
| **Program** | A recipe for a computer: steps it follows in order. |
| **Code** | The text of a program, written in a programming language. |
| **Console** | A place where you type code or commands and see the answer right away. |
| **Terminal** | A window where you type commands to your computer instead of clicking. |
| **Variable** | A labelled box that holds a value. |
| **Function** | A small machine: values go in, a result comes out. In Java it is called a *method*. |
| **Bug** | A mistake in code that makes it do the wrong thing. |
