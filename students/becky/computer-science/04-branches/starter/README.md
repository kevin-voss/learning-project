## How to run it

Open a terminal **in this folder** (`starter/`), then:

```bash
javac FolderOrder.java
```

```bash
java FolderOrder
```

`javac` = "translate my code for the computer". `java` = "now run it". Same for `Triangle` and `DateCheck`.

Changed the code? Run `javac` again before `java`, or you run the old version.
