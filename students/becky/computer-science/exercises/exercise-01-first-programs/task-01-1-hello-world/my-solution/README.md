## How to run it

Open a terminal **in this folder** (`my-solution/`), then:

```bash
javac Task01_1.java
```

```bash
java Task01_1
```

`javac` = "translate my code for the computer". `java` = "now run it". Changed the code? Run `javac` again before `java`, or you run the old version.
