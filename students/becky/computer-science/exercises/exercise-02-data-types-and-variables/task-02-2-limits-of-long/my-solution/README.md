Open a terminal **in this folder** (`my-solution/`), then:

```bash
javac LongLimits.java
```

```bash
java LongLimits
```

To look up the limits, try the little Java playground:

```bash
jshell
```

Then type `Long.MIN_VALUE` and press Enter. `/exit` leaves it.
