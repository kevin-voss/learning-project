# My solution · Task 07_1 ✏️

This is your desk. It is empty on purpose: you write the whole program yourself, from the first line to the last.

Create **`Info.java`**. The public class name must be **`Info`**. The [exercise page](../../README.md) explains methods, parameters and calls.

## How to run it

Open a terminal **in this folder** (`my-solution/`), then:

```bash
javac Info.java
```

```bash
java Info
```

## Test it

The task has tests: they check what your program prints. Any file and class name works, but this desk uses `Info.java`. Run from the repo root (where the `Makefile` is):

```bash
make test-task TASK=07_1
```

In Cursor, `/test` runs them and explains the first ❌.

## Rules for this desk

- Change anything you like here.
- Do not copy from [`../solution/`](../solution/README.md). Look there only when you are done.
- Stuck? Read the [exercise page](../../README.md) again, then the helpers in the [task](../README.md). In Cursor: `/stuck`, then `/check`.
