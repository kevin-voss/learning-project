# My solution · Task 08_1 ✏️

This is your desk. It is empty on purpose: you write the whole program yourself, from the first line to the last.

Create **`TotalPriceWithVat.java`** in this folder. The **public class** must be named `TotalPriceWithVat` (same as the file). The [exercise page](../../README.md) explains overloading and VAT rounding.

## How to run it

```bash
javac TotalPriceWithVat.java
java TotalPriceWithVat
```

## Test it

```bash
make test-task TASK=08_1
```

One part at a time: `make test-task TASK=08_1 PART=a`. In Cursor, `/test` runs the tests and explains the first failure.
