# My solution · Task 91_1 ✏️

This is your desk. It is empty on purpose: you write the whole program yourself, from the first line to the last.

Create **`RandomArraySort.java`** in this folder. The **public class** inside must be named **`RandomArraySort`**. The [exercise page](../../README.md) explains every idea you need.

## How to run it

From **this folder**:

```bash
javac RandomArraySort.java
java RandomArraySort
```

Type a seed (for example `42`), then Enter. You should see **three** lines in parentheses.

## Test it

The task has tests: they type a seed for you and check what your program prints. Any file and class name works if you keep one `main`. Run them from the main folder of the repo (where the `Makefile` is):

```bash
make test-task TASK=91_1
```

In Cursor, `/test` runs them and explains the first ❌.
