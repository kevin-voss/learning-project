# My solution · Task 92_1 ✏️

This is your desk. It is empty on purpose: you write the whole program yourself, from the first line to the last.

Create **`GameOfLife.java`** in this folder. The public class inside must be named **`GameOfLife`**. The [exercise page](../../README.md) explains every idea you need.

## How to run it

From **this folder**:

```bash
javac GameOfLife.java
java GameOfLife
```

Type the input by hand, or save input in a file and run:

```bash
java GameOfLife < input.txt
```

## Test it

```bash
make test-task TASK=92_1
```

(from the repo root, where the `Makefile` is)
