# My solution · Task 06_1 ✏️

This is your desk. It is empty on purpose: you write the whole program yourself, from the first line to the last.

Create one file: **`even-sum.mjs`** in this folder. The [exercise page](../../README.md) explains every idea you need.

## How to run it

From **this folder** (`my-solution/`):

```bash
node even-sum.mjs
```

## Test it

The task has tests: they check what your program prints. Run them from the **repository root** (where the `Makefile` is):

```bash
make test-task TASK=06_1 STUDENT=becky SUBJECT=informatik
```

When your work matches the sample solution:

```bash
make test-task TASK=06_1 STUDENT=becky SUBJECT=informatik SOLUTION=1
```

In Cursor, `/test` runs them and explains the first ❌ (and makes extra tests for edge cases when you ask).
