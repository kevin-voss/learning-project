# Becky · Staatsrecht

> [!PICTURE]
> A quiz is a stack of cards. Each card asks one thing. You pick the answers that fit. The card then shows what was right, what was wrong, and a little more so the idea sticks.

Staatsrecht has no coding exercises. The quizzes are in German. Each lecture becomes a multiple-choice quiz. Open a lecture and answer on that page. This browser remembers your answers.
