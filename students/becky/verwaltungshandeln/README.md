# Becky · Verwaltungshandeln

> [!PICTURE]
> A quiz is a stack of cards. Each card asks one thing. You pick the answers that fit. The card then shows what was right, what was wrong, and a little more so the idea sticks.

Verwaltungshandeln has no coding exercises. Each lecture becomes a multiple-choice quiz. You answer on the [home page](../../../hub/index.html#tasks). This browser remembers your answers.
