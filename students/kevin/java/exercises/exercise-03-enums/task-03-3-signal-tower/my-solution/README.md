# My solution · Task 03_3 ✏️

This is your desk. It is empty on purpose: you write the whole program yourself, from the first line to the last.

Create a file such as `SignalTower.java`. The public class inside must match the file name. Put `public static void main(String[] args)` in that class (or in another `.java` file in this folder). Ideas: [exercise page](../../README.md) — section 4 has the switch expression.

## How to run it

From this folder:

```bash
javac *.java
java SignalTower
```

(Use your class name if you chose a different one.)

## Test it

The task has tests: they type the inputs for you and check what your program prints. Any file and class name works. Run them from the main folder of the repo (where the `Makefile` is):

```bash
make test-task TASK=03_3 STUDENT=kevin SUBJECT=java
```

Does the task have parts a), b) …? Test one part alone: `make test-task TASK=03_3 PART=a`. In Cursor, `/test` runs them and explains the first ❌ (and makes extra tests for edge cases when you ask).
