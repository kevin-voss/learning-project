# My solution · Task 08_1 ✏️

This is your desk. It is empty on purpose: you write the whole program yourself, from the first line to the last.

Create a file such as `ParcelEvents.java`. The public class inside must match the file name. Put `public static void main(String[] args)` in that class (or in another `.java` file in this folder). Ideas: [exercise page](../README.md) and the sheets linked there.

## How to run it

From this folder:

```bash
javac *.java
java ParcelEvents
```

(Use your class name if you chose a different one.)
