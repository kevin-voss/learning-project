# My solution · Task 08_2 ✏️

This is your desk. It is empty on purpose: you write the whole program yourself, from the first line to the last.

Create a file such as `BusyPostOffice.java`. The public class inside must match the file name. Put `public static void main(String[] args)` in that class. Ideas: [exercise page](../README.md) and [Virtual threads](../../../../../../../sheets/java/concurrency/virtual-threads.md).

## How to run it

From this folder:

```bash
javac *.java
java BusyPostOffice
```

(Use your class name if you chose a different one.)
