# Kevin · Spring Boot · Exercises

One folder = one exercise (one exercise sheet). Inside: one folder per task, each with `README.md`, `my-solution/` and `solution/`. Do them in number order; the [subject page](../README.md) says what to read before each one. Every task is plain Java that simulates one Spring or Hibernate mechanism — test it with `make test-task TASK=01_1 STUDENT=kevin SUBJECT=spring-boot`.
