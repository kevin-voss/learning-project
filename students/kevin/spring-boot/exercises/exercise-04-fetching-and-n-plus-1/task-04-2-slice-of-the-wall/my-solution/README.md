# My solution · Task 04_2 ✏️

This is your desk. It is empty on purpose: you write the whole program yourself, from the first line to the last.

Create a file such as `SliceOfTheWall.java`. The public class inside must match the file name. Put `public static void main(String[] args)` in that class (or in another `.java` file in this folder). Ideas: [exercise page](../../README.md).

## How to run it

From this folder:

```bash
javac *.java
java SliceOfTheWall
```

(Use your class name if you chose a different one.)

## Test it

The task has tests: they type the inputs for you and check what your program prints. Any file and class name works. Run them from the main folder of the repo (where the `Makefile` is):

```bash
make test-task TASK=04_2 STUDENT=kevin SUBJECT=spring-boot
```

In Cursor, `/test` runs them and explains the first ❌ (and makes extra tests for edge cases when you ask).
